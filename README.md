# RPM HUB
Many apps don't ship RPMs, or at least not in a yum repo so that it can be kept updated using package managers like dnf.
This is a collection of community-maintained unofficial RPMs built from official sources.

# Apps

## Postman

#### Step 1: Enable the repo
```sh
sudo dnf copr enable coder966/postman
```

#### Step 2: install it
```sh
sudo dnf install postman
```

## IntelliJ IDEA Ultimate

#### Step 1: Enable the repo
```sh
sudo dnf copr enable coder966/intellij-idea-ultimate
```

#### Step 2: install it
```sh
sudo dnf install intellij-idea-ultimate
```
## SoapUI
